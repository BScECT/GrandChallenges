# Introduction to Python

This is the teachbook for the course Exploring the Grand Challenges (ECTB1110A) for first-year BSc Earth, Climate & Technology students at TU Delft. With this teachbook you will learn how to use the programming language **Python** to explore the grand challenges we are facing as a society. This teachbook contains a mix of theory and exercises. You can work in pairs on the exercises in class. The teaching assistants in class are available for questions you may encounter.

**Python** is a computer programming language that is widely used in both academia and industries related to Earth, Climate and Technology, Civil Engineering and Environmental Engineering. Being skilled in Python will help you to analyse and visualise data and results. You can even build very advanced computer models using Python. This teachbook will get you started with the very basics of Python. But just like any other language, only you practicing yourself will make you actually proficient.

We will only cover the concepts from a helicopter view, for more details on how to use specific parts of Python you will need to turn to other sources. We recommend you take a look at the following online book: <a href="https://allendowney.github.io/ThinkPython/">"Think Python 2nd Edition" by Allen B. Downey</a>. It contains a more detailed overview of the Python language and it's functions.

## Notebooks

In this course, you will use **Python Notebooks** with Jupyter Notebooks or Jupyter Lab for exercises. These notebooks allow you to run scripts in segments, called cells, enabling you to execute specific code parts individually. To run a cell, select it and press **'run cell'** or use the **Shift + Enter** shortcut. This is particularly useful for data analysis, as it allows for quick modifications or the addition of explanations, formulas, or visualizations.
