Hardware vs. Software, and Your C: Drive

Your computer has two basic parts: hardware (the physical components — your hard drive, memory, processor, etc.) and software (the programs and operating system that run on that hardware, like Windows itself, or apps such as Word or a browser).

Your C: drive is the main storage drive inside your computer. It's split into two functional parts:

Operating system space — where Windows and installed programs live. You shouldn't need to touch this.
Free space — the rest of the drive, available for you to store your own files, documents, and folders.
Finding Your C: Drive (Not OneDrive)

Many computers are set up so that "Documents" or "Desktop" automatically save to OneDrive (cloud storage) instead of your local C: drive. To find your actual C: drive:

Open File Explorer (folder icon in the taskbar, or press Windows + E).
In the left sidebar, look for "This PC" and click it.
Under "This PC," you'll see your drives listed — click on Local Disk (C:). This is different from any folder labeled "OneDrive."
Creating Your Folder Structure

Once you're in the C: drive:

Check if you already have a folder called "Bachelor". If not, right-click in empty space → New → Folder → name it Bachelor.
Open the Bachelor folder, then create a new folder inside it called "year1".
Open "year1", then create a new folder inside it called "GrandChallenges".
Open "GrandChallenges", then create a new folder inside it called "week1".

You should end up with this path: C:\Bachelor\year1\GrandChallenges\week 1
