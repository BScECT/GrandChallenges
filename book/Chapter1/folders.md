# Hardware vs. Software

Your computer has two basic parts: hardware (the physical components: your hard drive, memory, processor, etc.) and software (the programs and operating system that run on that hardware, like Windows itself, or apps such as Word or a browser).

## For windows users:

Your C: drive is the main storage drive inside your computer. It's split into two functional parts:

Operating system space — where Windows and installed programs live. You shouldn't need to touch this.
Free space — the rest of the drive, available for you to store your own files, documents, and folders.
Finding Your C: Drive (Not OneDrive)

Many computers are set up so that "Documents" or "Desktop" automatically save to OneDrive (cloud storage) instead of your local C: drive. To find your actual C: drive:

Open File Explorer (folder icon in the taskbar, or press Windows + E).
In the left sidebar, look for "This PC" and click it.
Under "This PC," you'll see your drives listed — click on Local Disk (C:). This is different from any folder labeled "OneDrive."
Creating Your Folder Structure

Once you're in the C: drive:

Check if you already have a folder called "Bachelor". If not, right-click in empty space → New → Folder → name it Bachelor.
Open the Bachelor folder, then create a new folder inside it called "year1".
Open "year1", then create a new folder inside it called "CourseName". You can choose the code of this course (i.e. ECTB1110) or you can include the name of the course (e.g. GrandChallenges) or a variation (e.g. ECTB1110_GrandChallenges). Choose according to your preference or think of your own filenaming system. 
Open "GrandChallenges", then create a new folder inside it called "week01".

You should end up with this path: C:\Bachelor\year1\CourseName\week01. This is where you will save all the documents related to this course. Make sure to use this folder structure for your other courses as well to keep the overview in your laptop.

## For mac users:

Your Mac's internal storage (usually labeled "Macintosh HD") is where macOS and your personal files live. It's split into two functional parts:

System space — where macOS and installed applications live. You shouldn't need to touch this.
Your home folder — the space available for you to store your own files, documents, and folders.

Finding Your Home Folder (Not iCloud Drive)
Many Macs are set up so that "Documents" or "Desktop" automatically save to iCloud Drive (cloud storage) instead of your Mac's local storage. To find your actual home folder:

Open Finder (the smiley-face icon in the Dock, or press Cmd + Space and type "Finder").
In the left sidebar, under "Favorites," look for your username next to a house icon, and click it. This is different from any folder labeled "iCloud Drive."
If it's not showing in the sidebar, click Finder in the menu bar → Settings → Sidebar, and make sure your home folder (your username) is checked. You can also always jump there via Go → Home in the Finder menu bar.

Creating Your Folder Structure

Once you're in your home folder:
Check if you already have a folder called "Bachelor". If not, right-click in empty space → New Folder → name it Bachelor.
Open the Bachelor folder, then create a new folder inside it called "year1".
Open "year1", then create a new folder inside it called "CourseName". You can choose the code of this course (i.e. ECTB1110) or you can include the name of the course (e.g. GrandChallenges) or a variation (e.g. ECTB1110_GrandChallenges). Choose according to your preference or think of your own filenaming system.
Open "GrandChallenges", then create a new folder inside it called "week01".

You should end up with this path: ~/Bachelor/year1/CourseName/week01 (shown in Finder as Macintosh HD → Users → yourusername → Bachelor → year1 → CourseName → week01). This is where you will save all the documents related to this course. Make sure to use this folder structure for your other courses as well to keep the overview on your laptop.
